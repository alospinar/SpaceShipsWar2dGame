# Spaceship War

## English

**Spaceship War** is an arcade game created as a practical project to improve C# programming skills and explore core Unity game-development techniques.

### Features and learning goals

- Use of the Singleton design pattern.
- Particle effects.
- Enemy AI and enemy behavior management.
- Multiple game scenes.
- Enemy loops and repeated movement patterns.
- Camera shake effects.
- Background music and sound effects.
- Runtime enemy spawning.
- Enemy movement along predefined paths.
- Use of `while`, `do while`, and `foreach` loops.
- Use of Unity coroutines.
- Creation of different prefab variants.

### Controls

| Action | Controls |
| --- | --- |
| Move | Arrow keys or `W`, `A`, `S`, `D` |
| Shoot | `X` or `Space` |

## Español

**Spaceship War** es un juego arcade creado como un proyecto práctico para mejorar las habilidades de programación en C# y explorar técnicas fundamentales de desarrollo de videojuegos en Unity.

### Características y objetivos de aprendizaje

- Uso del patrón de diseño Singleton.
- Efectos de partículas.
- Inteligencia artificial y gestión del comportamiento de los enemigos.
- Diferentes escenas de juego.
- Bucles y patrones de movimiento repetidos para los enemigos.
- Efectos de cámara con movimiento (`camera shake`).
- Música de fondo y efectos de sonido.
- Generación de enemigos durante la ejecución (`runtime spawning`).
- Movimiento de los enemigos siguiendo caminos predefinidos.
- Uso de ciclos `while`, `do while` y `foreach`.
- Uso de coroutines de Unity.
- Creación de diferentes variantes de prefabs.
